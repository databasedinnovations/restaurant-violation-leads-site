# Restaurant Violation Leads — marketing site

Public marketing/subscribe site for Restaurant Violation Leads, served via
GitHub Pages at [restaurantviolationleads.com](https://restaurantviolationleads.com).

This is a static, single-page site — no build step, no framework. Edit
`index.html` and push to `master` to deploy.

This repo intentionally contains **no** scraper, classification, or
customer data — that lives in the private `Health_Inspection_Leads` repo.
This site only shows genericized/illustrative example content, never real
establishment data.
